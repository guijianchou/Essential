# Essential (Toolbox) - Changelog / 项目修改记录

================================================================================
PART 1: ENGLISH CHANGELOG & RELEASE NOTES
================================================================================

## Version 0.4.3 (2026-09-10)
- Issue Overview Enhancement: Added "Priority view / All findings" switch; top 5 priority findings clearly display their proportion relative to the total; All findings view automatically expands categories to avoid findings being hidden in collapsed groups.
- Filter Interaction: Selecting a log source or severity automatically transitions to the All findings view and expands matching categories. Clicking the active source re-expands without resetting manual collapse states.
- Search Capabilities: Added search across Event ID, provider name, and localized titles. Purely numeric queries perform exact Event ID matching, with accurate match counts and search hints.
- Regression & Verification: WindowsUpdateClient 20 / Volsnap 36 synthetic regressions passed across XAML binding, search, bilingual strings, and theme switches; 19 historical reads and 54 analysis regressions passed.

## Version 0.4.2 (2026-09-10)
- Health Overview: Simplified health summary card to show High / Medium / Low counts alongside top recommended actions with direct detail navigation. Historical filters no longer distort current audit summaries.
- Layout & Token: Sidebar removed redundant titlebar padding, keeping navigation entries at the top. Collapsed sidebar token display uses line icons and flyouts without expanding pane.
- Build & Artifacts: Standardized build outputs to artifacts/bin, artifacts/obj, and artifacts/publish (x64 default). Consolidated documentation into docs.

## Version 0.4.1 (2026-09-10)
- Kernel Management: "Download or update" compares local CLI semantic versions against official releases, skipping downloads when local is identical or newer. Data directory kernels take precedence over application directory copies.
- Pi CLI Concurrency Fix: Resolved brief process file locking upon Pi exit with up to 3.1s bounded retries.
- Zero-Event Handling: Zero-event scans explicitly report "No AI analysis conducted" and record reason. Added "Reanalyze selected range" context menu to re-evaluate 1d/2d/1w with the current kernel.
- Kernel Cache Isolation: Analysis caches separated per kernel; explicit reanalysis purges cache.

## Version 0.4.0 (2026-09-10)
- Rebranding: Application renamed to "Essential" (Chinese: 工具箱). Executables and release outputs updated accordingly; preserved data directory, settings, kernels, and history.
- Navigation Consolidation: Overview and Trends consolidated into "Security Audit" with a clean health status card.
- Hub Task Architecture: Settings "Security Audit" transformed into "Hub", binding sidebar entries to individual AGENTS.md rule cards under chains/{taskId}/AGENTS.md.

## Version 0.3.11 (2026-09-10)
- Token Tracking: Persistent Token totals in sidebar. SQLite records kernel-reported in/out tokens in TokenUsage table, deduplicated per request.
- Appearance Settings: Added configurable token display periods (local calendar Day, Monday-aligned Week, or Month).
- Codex Responses Protocol: Addressed Codex 0.153.4 internal Responses-Lite gateway incompatibility via model_catalog_json, disabling internal Lite while maintaining streaming and AGENTS.md.

## Version 0.3.10 (2026-09-09)
- Sidebar Viewport: Fixed zero-height scrolling bug when pane toggled.
- Task Strategy Migration: Security audit AGENTS.md migrated to chains/security-audit/AGENTS.md. Codex reads AGENTS.md from isolated ephemeral working directories.

## Version 0.3.9 (2026-09-09)
- Process-based AI Kernels: Replaced direct HTTP AI calls with isolated Codex / Pi CLI processes. Removed legacy assistant mode.
- Connection Testing: Connection tests exercise live kernels with minimal payloads and display real-time token counts.

## Version 0.3.8 (2026-09-09)
- Theme Assets: Removed legacy unthemed logos; introduced light/dark adaptive assets.
- Build Isolation: Debug and Release builds separated into versioned directories.

## Version 0.3.7 (2026-09-08)
- Workflow Reordering: Centered scan progress and status in sidebar with independent scrolling.
- Analysis Depth: Tuned AI prompt depth by severity (High: chronological evidence chain & verification; Medium: pattern & alternative checks; Low: concise routine check).

## Version 0.3.6 (2026-09-08)
- Responses API: Standardized instructions/input, reasoning effort, and max_output_tokens.
- SSE Streaming Completion: Enforced strict requirement for response.completed before accepting results.

## Version 0.3.5 (2026-09-08)
- Data Isolation: User configurations, diagnostic logs, and databases isolated to LocalAppData.
- Standalone Release: First self-contained x64 distribution package.

## Version 0.3.4 (2026-09-07)
- Dual Modes: Extended mode (standard user, skips Security) and Full-access mode (same-user UAC elevation, covers 5 channels).
- Health Score UI: Integrated compact health overview, 7-day selector, and source filtering.

## Version 0.3.3 ~ 0.2.0 (2026-09-03 ~ 2026-09-07)
- Model tiers: Support for GPT-5.6 Luna / Terra / Sol and GPT-6 Astra.
- Multi-channel log ingestion: Application, System, Setup, ForwardedEvents, and Security.
- WinUI 3 modernization: MicaAlt backdrop, Segoe UI Variable typography, bilingual English/Chinese localization.

- 设置新增“优化”标签，按 Luna → Terra → Sol → Astra 单向优化历史双语分析；未知型号受保护，未标注与别名记录仅允许 Astra 优化。备用入口也必须请求选定型号。
- 每条分析保存并显示模型标签、原模型与优化时间；优化逐批保存、校验双语完整性和键对应关系，保留原始证据及未知字段，拒绝并发覆盖并更新健康评分。
- Fast scan 重启后恢复最近成功审计的 ScanEnd，避免回到初始四小时窗口；Full scan 保持 24 小时。
- 首页 Health Score 上方增加最近七天日期按钮，联动当天最近一份可读审计、评分、来源分类和问题详情，空日期显示空态。
- 1D / 7D / 30D 切换只发布一次结果，复用图表序列、固定分类图高度，加入短淡入与位移动画，并遵循系统动画设置。

## 0.3.2 / 2026-09-07
- Settings 的 AI analysis 将 Endpoints 移到 Audit policy 上方。
- AI 流式和普通 JSON 响应统一检查失败、取消及不完整状态；远端取消或输出不完整时停止扫描，不再重复请求。输出 token 用尽时给出明确提示。
- 某个并行批次最终失败后取消其他请求及排队批次，保留原始失败原因，避免远端失败后仍长时间显示处理中。
- 临时网络故障最多尝试两次；请求超时不在同一入口重复等待，仍支持可用的 Fallback。连接等待显示耗时，重试显示等待时间和次数。
- 增加本地 HTTP 模拟回归，覆盖流式取消、失败切换、重试上限、并行停止与慢响应进度；服务端原始错误内容不再写入界面或诊断日志。

## 0.3.1 / 2026-09-07
- 修复 System / Application 查询漏掉 Critical 事件的问题，补齐 Setup 采集和 Security 审计事件；防火墙审计改从正确的 Security 通道读取。Full scan 仍固定为 24 小时。
- 区分 System BugCheck 1001 与 Application 1001；问题合并保留日志和来源边界，AI 提示明确分析 Kernel-Power 41 等异常重启事件，不把事件本身当作电源故障证据。
- 首页增加总览、Application、Security、Setup、System 来源标签，联动问题数量、严重程度筛选和详情。
- 侧栏显示阶段完成度百分比、当前阶段百分比及批次数；读取分组更新不会重置流程，失败不会显示为 100%。

## 0.3.0 / 2026-09-07
- 移除 Dashboard 顶部重复扫描指示和手动刷新；最新记录损坏时回退到最近可用记录，读取失败时保留已展示结果。

## 0.2.0 / 2026-09-07
- 扫描进度和保存时间移入可折叠侧栏，显示路由、批次、双语分析和历史补译的实际状态。
- 侧栏节点固定高度，流式详情附批次编号并限频刷新；状态淡入和真实批次进度平滑过渡，遵循系统动画设置。

- 保留独立日志证据，限制重复事件采样，显示收集、实际分析和过滤数量；未分析的扫描不计为健康满分。
- 修复管理员启动时过早访问 WinUI 资源导致的主窗口崩溃，保留 requireAdministrator。
